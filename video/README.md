# オンクリ動画ドラフト

`index.html` は、150秒版の構成・字幕・シーン切り替えをブラウザで確認するための非公開ドラフトです。

## 確認方法

リポジトリのルートで次のコマンドを実行し、表示されたURLの `/video/` を開きます。

```powershell
node serve.js
```

字幕の納品用データは `online-clinic-guide.srt`、生成した説明イラストは `../video-assets/` にあります。

## 最終制作時の確認

- ナレーションは150秒以内に収める
- 医療機関・医師・薬剤師に、薬効・副作用・禁忌・費用表現を確認してもらう
- 予約先の公式LINE URLと動画内のQRコードを最終確認する
- 字幕と音声の表記を一致させる
- YouTube公開時は、概要欄にも費用、配送、注意事項、公式サイトURLを記載する
